[Stacks](https://morphing.cloud/hypercard/?utm_campaign=unsolicited_traffic&utm_medium=web&utm_source=taoofmac.com) runs classic [HyperCard](/space/apps/hypercard) stacks directly on modern [macOS](/space/com/apple/macos#macos-formerly-mac-os-x), with period-accurate typography, sound, MacinTalk speech synthesis, cross-stack navigation and limited HyperTalk support–all without having to run a complete classic Mac emulator.

The built-in browser provides one-click access to the Internet Archive’s collection, which is probably the nicest way to explore old stacks without first becoming an amateur digital archivist. HyperCard was one of the formative pieces of software in my life, and making its strange, inventive corpus this easy to browse is exactly what preservation tooling should do.

Stacks is still an alpha, but this already feels much closer to using HyperCard than using web emulators…
