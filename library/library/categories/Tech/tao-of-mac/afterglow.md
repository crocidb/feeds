[Afterglow](https://morphing.cloud/afterglow/?utm_campaign=unsolicited_traffic&utm_medium=web&utm_source=taoofmac.com) runs original [After Dark](https://en.wikipedia.org/wiki/After_Dark_(software)?utm_campaign=unsolicited_traffic&utm_medium=web&utm_source=taoofmac.com) 68k screen saver modules natively on modern [macOS](/space/com/apple/macos#macos-formerly-mac-os-x) without requiring a classic Mac OS installation or Apple ROMs. Rather than remake Flying Toasters, Fish!, Starry Skyline and the rest, it uses the Musashi 68k emulator and reimplements just enough of the old Macintosh Toolbox and operating-system APIs to run the original code.

Modules are not included, but the app can import them from module files, disk images and archives–or browse releases on the Internet Archive–and includes a modern macOS screen saver module. This is exactly the kind of software preservation I like: focused, technically elegant and making the original work useful again rather than merely documenting it.

I may have spent a ridiculous amount of time getting [Flying Toasters running on an ESP32-S3](/space/blog/2026/06/14/1400#shoehorning-flying-toasters-into-a-esp32-s3), but Afterglow is a much saner way to revisit the rest of After Dark…
