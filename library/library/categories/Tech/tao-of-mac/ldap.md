The Lightweight Directory Access Protocol, the bastard child of the original X.400-oriented DAP (Directory Access Protocol) and [TCP/IP](/space/protocols/tcp/ip).

The LDAP protocol is often confused with the data or directory structure itself, and was hailed as a must-have feature in the battle for corporate-oriented file and print services (years after [Novell](/space/com/novell) got it right the first time).
