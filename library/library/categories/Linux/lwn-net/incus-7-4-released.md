[Version 7.4](https://discuss.linuxcontainers.org/t/incus-7-4-has-been-released/27169) of the Incus container and virtual-machine management system has been released. Notable changes in this release include UEFI Secure Boot key management, "near-live" migration of containers between Incus instances, as well as burst I/O limits for disk and network devices.
