[Version 1.33.0](https://github.com/ubuntu/lightdm/releases/tag/1.33.0) of the [LightDM](https://github.com/ubuntu/lightdm#lightdm-display-manager) display manager has been released. This is the [first release in four years](https://discourse.ubuntu.com/t/lightdm-1-33-0-released/85962): the project had been sponsored by Canonical but was [effectively unmaintained](https://discourse.ubuntu.com/t/current-status-of-lightdm/29048/17?) in recent years. It has been [transferred to a new community repository](https://discourse.ubuntu.com/t/current-status-of-lightdm/29048/23) and is now maintained by Joshua Peisach and Neal Gompa.

The new release includes Qt6 support, code optimizations, and a list of other fixes that had been in limbo pending a new release.
