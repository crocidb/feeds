[Quickshell](https://quickshell.org/) is a toolkit for building desktop components, such as toolbars or menus. It uses [QML](https://doc.qt.io/qt-6/qmlreference.html), which is a declarative language for designing GUI applications. Quickshell helps developers create graphical tools for common desktop use cases with a focus on ease of development. It offers a convenient method for writing user interfaces and has been adopted by a number of projects, such as [caelestia-shell](https://github.com/caelestia-dots/shell#caelestia-shell) and [DankMaterialShell](https://danklinux.com/), that provide desktop environments for minimal window managers like [Sway](https://swaywm.org/) and [niri](https://niri-wm.github.io/niri/).
