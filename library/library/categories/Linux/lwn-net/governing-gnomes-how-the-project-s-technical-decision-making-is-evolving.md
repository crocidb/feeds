Emmanuele Bassi kicked off a project to improve GNOME's technical governance with a [presentation about his ideas](https://lwn.net/Articles/1034684/) ([video](https://www.youtube.com/watch?v=n3SviPlMyhM)) at [GUADEC 2025](https://events.gnome.org/event/259/). His nudging has led the project to, slowly, work on creating more formal structures for technical governance. It is adopting a teams structure and looking toward creating a steering committee, as well as bootstrapping a Request for Comments (RFC) process. If adopted, GNOME would require RFCs for design, user experience, architectural, and other changes that carry a major impact on the project.
