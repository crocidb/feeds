[Version 0.11](https://wayfire.org/2026/07/24/Wayfire-0-11.html) of the [wlroots](https://gitlab.freedesktop.org/wlroots/wlroots#wlroots)-based [Wayfire](https://wayfire.org/) Wayland compositor has been released. Notable changes include better fractional scaling, per-output [ICC profiles](https://en.wikipedia.org/wiki/ICC_profile), support for additional Wayland protocols, and more.
