Firefox has finally begun supporting Vulkan Video decoding to complement their long-used VA-API support on Linux. This is good news for the official NVIDIA Linux graphics driver stack as it's been the notable vendor not supporting the Video Acceleration API. But prior to Firefox rolling out its experimental Vulkan Video support, an independent implementation of VA-API built atop NVIDIA's NVDEC interface has been available for supporting GPU video acceleration in Firefox.
