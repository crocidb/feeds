My wife and I got a chance to go to a place that lets you paint pottery and then have it fired. The pottery is all pre-made; you just get to paint it.

It’s been a very long time since I’ve worked with a physical art medium, so the mug looks kinda dumpy. I did alright with the Racket logo on the bottom-inside of the mug though!

![A poorly-painted blue mug](/img/racket_mug0.jpeg) ![A passable freehanded Racket logo](/img/racket_mug1.jpeg)

I’m working on some fun projects with Racket. It’s been a really enjoyable language to work with. If you haven’t given it a whirl, I recommend checking it out. The docs on the [official Racket site](https://racket-lang.org) are very good, and there are some absolutely *stellar* gentle introductions to the language like [How to Design Programs](https://htdp.org) that I would recommend.
