Give an agent an access token and it spreads: into the context window, into tool call logs, into notes it keeps between steps. Each copy works from anywhere, long after the fact.

[Relay](https://workos.com/docs/pipes/relay?utm_source=daringfireball&utm_medium=newsletter&utm_campaign=q32026&utm_content=docs) keeps the credential at WorkOS. Your agent names the user, WorkOS attaches that token, refreshes it, and releases it only to allowlisted hosts. A hijacked agent session is a live process you can kill.
