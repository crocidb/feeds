Not a month goes by without someone claiming they’ve killed tech writing. A few weeks ago, it was [CodeWiki and its docs theatre](https://passo.uno/ai-wikis-docs-teather-as-a-service/). Now it’s the turn of Claude Skills and their ecosystem of Markdown instructions served as if they were executable code or macros. Docs, though, are tougher than they’d expect, because they’re the strongest signals in a sea of noise, and because they’re pretty much everywhere. Including, well, skills.
