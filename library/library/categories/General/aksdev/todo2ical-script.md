I made a simple todo2ical script that converts todo.txt file into an ical file.

It's not much really. I just wanted some nice way to get notifications for my due tasks without separate apps.

You can add the files it produces as read-only external calendars to your calendar thing.

Here's link to the source code: [https://codeberg.org/akselmo/todo2ical](https://codeberg.org/akselmo/todo2ical)

I just have it to spit out a file to a random endpoint in my server and then just use that in my calendar apps.

I gotta admit, I'm tempted to go back to regular caldav tasks at times.. But I really like the workflow of [Komodo](https://flathub.org/en/apps/org.kde.komodo) and I would feel bad for not using it anymore.
