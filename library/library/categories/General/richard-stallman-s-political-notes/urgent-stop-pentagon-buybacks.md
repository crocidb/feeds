 US citizens: call on the Senate to stop Pentagon contractors' stock buybacks, and make them get the Pentagon's permission to release a dividend.

[Check this action.](https://actionnetwork.org/letters/tell-the-senate-crackdown-on-pentagon-contractor-profiteering?nowrapper=true)

Clearly it would be better if paying a dividend required permission from some organization more likely to be strict, but this rule is a step forward anyway. And so is the stock buyback rule.

See the [instructions](/actionnetwork-letter-instructions.html) for how to sign this letter campaign without running any nonfree JavaScript code--not trivial, but not hard.
