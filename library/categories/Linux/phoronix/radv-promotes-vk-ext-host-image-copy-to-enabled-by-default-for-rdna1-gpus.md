Going back to July 2025 the open-source Radeon RADV Vulkan driver has offered experimental host image copy support with the API's VK\_EXT\_host\_image\_copy extension. This has been for RDNA1 and newer GPUs while now GFX10 RDNA 1 GPUs have this extension enabled by default while also enabling experimental support for prior GFX9 era GPUs too...
