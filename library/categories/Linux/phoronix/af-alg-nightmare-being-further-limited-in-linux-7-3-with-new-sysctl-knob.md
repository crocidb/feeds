The Linux kernel's AF\_ALG interface was deprecated in Linux 7.2. This interface for letting user-space programs interact directly with the Linux kernel crypto API has proven to be a "massive attack surface" due to a variety of security concerns. With its deprecation in Linux 7.2, some AF\_ALG features are already removed and for Linux 7.3 this interface is being further restrained...
