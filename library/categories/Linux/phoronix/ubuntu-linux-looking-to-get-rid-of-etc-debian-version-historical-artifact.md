Ubuntu Linux has shipped /etc/debian\_version that is carried over from upstream Debian and in turn just indicating the Debian Sid development version from which the packages are arrived. Besides it being inaccurate, /etc/os-release has been the long preferred standard for reading the OS release information. Thus finally Ubuntu developers are looking at dropping the /etc/debian\_version file...
