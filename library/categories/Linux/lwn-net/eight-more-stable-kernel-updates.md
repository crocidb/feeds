 Greg Kroah-Hartman has announced the release of the [7.3.1](https://lwn.net/Articles/1104178/), [7.2.14](https://lwn.net/Articles/1104179/), [6.18.60](https://lwn.net/Articles/1104180/), [6.12.115](https://lwn.net/Articles/1104181/), [6.6.161](https://lwn.net/Articles/1104182/), [6.1.191](https://lwn.net/Articles/1104183/), [5.15.224](https://lwn.net/Articles/1104184/), and [5.10.273](https://lwn.net/Articles/1104185/) stable kernels. As usual, he advises all users to update—advice that seems especially wise given the increased number of security-relevant bug fixes that the kernel is seeing these days. [Edit: the 7.2.15 stable release is already [in review](https://lwn.net/Articles/1104186) as well.]
