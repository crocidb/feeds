[Version 2.47](https://inbox.sourceware.org/binutils/87o6fty5pz.fsf@redhat.com/) of [GNU Binutils](https://www.gnu.org/software/binutils/) has been released. In addition to the usual bug fixes there are some notable new features in this release including added support for a number of RISC-V standard extensions, a command-line option (-M annotate) which displays the symbol for undefined instructions for AArch64, and more. The 32-bit s390 target has been deprecated with this release.
