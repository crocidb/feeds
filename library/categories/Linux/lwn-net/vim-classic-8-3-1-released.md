[Version 8.3.1](https://vim-classic.org/news/vim-8.3.1-released.html) of [Vim Classic](https://vim-classic.org/)—a long-term support fork of Vim maintained without LLM assistance—has been released.

>  This release includes applicable Vim patches up to Vim 8.2.3237, including numerous bug fixes, minor features, and compatibility improvements for Vim plugins. This release also removes Python 2 support from Vim Classic.

The [full list of changes](https://git.sr.ht/~sircmpwn/vim-classic/refs/v8.3.1) in this release is available on sourcehut.
