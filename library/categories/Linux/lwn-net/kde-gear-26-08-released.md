[Version 26.08](https://kde.org/announcements/gear/26.08.0/) of the [KDE Gear](https://en.wikipedia.org/wiki/KDE_Gear) collection of applications has been released. Notable changes in this release include improvements in the [signing](https://docs.kde.org/stable_kf6/en/okular/okular/signatures.html) features of [Okular](https://okular.kde.org/), improved file-grouping features in the [Dolphin](https://apps.kde.org/dolphin/) file manager, and a number of enhancements to the [Kdenlive](https://kdenlive.org/) video editor. See the [changelog](https://kde.org/announcements/changelogs/gear/26.08.0/) for a full list of updates, enhancements, and bug fixes.
