Version 2.56 of the [Git](https://git-scm.com/) distributed version-control system has been released. It has 748 non-merge commits since [Git 2.55 was released](https://lwn.net/Articles/1080188/) back in June; those commits came from 104 developers, 39 of whom are first-time contributors. New features include a safer workflow for conflict resolution, smaller path-walk repacks, a new git history drop sub-command, and much more. LWN [looked at Git 2.56](https://lwn.net/Articles/1094575/) recently and the GitHub blog has a [lengthy look at 2.56](https://github.blog/open-source/git/highlights-from-git-2-56/) as well.
