[Version 2.44](https://lwn.net/ml/all/teaVXxrfQH2qv0xBul7sXg@gentoo.org) of the GNU C Library has been released. Changes include a new /etc/tunables.conf file for the system-wide setting of tunable parameters, a new tunable to control the use of transparent huge pages for read-only executable segments, a number of math-function improvements, a handful of security fixes, and more.
