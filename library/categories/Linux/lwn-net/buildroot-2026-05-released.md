[Version 2026.05](https://lore.kernel.org/buildroot/87fr2wpxhj.fsf@dell.be.48ers.dk/T/#u) of the [Buildroot](https://buildroot.net/) tool has been released. Buildroot simplifies and automates the process of building embedded Linux systems using cross-compilation. Notable changes in this release include support for Arm Neoverse cores, addition of XFS rootfs generation, as well as many package updates and bug fixes. See the [CHANGES](https://gitlab.com/buildroot.org/buildroot/-/blob/2026.05/CHANGES) file for the full list.
