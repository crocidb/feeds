The PostgreSQL Global Development Group has [announced](https://www.postgresql.org/about/news/postgresql-19-released-3449/) the release of PostgreSQL 19. Notable features in this release include the introduction of the REPACK (CONCURRENTLY) command to optimize tables without disruption to ongoing operations, better control over plan stability and query performance with the new pg\_plan\_advice extension, and a number of performance improvements.

In September, LWN [covered](https://lwn.net/Articles/1092003/) the removal of several features initially slated for this release. See the [release notes](https://www.postgresql.org/docs/19/release-19.html) for a full list of new features and changes.
