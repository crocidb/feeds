 Pierre-Emmanuel Patry and Arthur Cohen gave a talk at [ RustConf 2026](https://rustconf.com/) on the status of the Rust frontend for GCC (gccrs), with a particular eye toward the goal of [ compiling the Linux kernel](https://lwn.net/Articles/1083202/). Patry gave a follow-up talk for a more kernel-focused audience at [ Kangrejos](https://kangrejos.com/) the next week, which Cohen could not attend. The [ gccrs project](https://rust-gcc.github.io/) is making good progress overall, but it will still be some time until the compiler is usable.
