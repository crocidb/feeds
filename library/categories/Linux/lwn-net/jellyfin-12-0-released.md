[Version 12](https://jellyfin.org/posts/jellyfin-release-12.0/) of the [Jellyfin](https://jellyfin.org/) media-management system has been released. Notable changes include [database performance improvements](https://jellyfin.org/posts/jellyfin-release-12.0/#tuning-the-new-database), [an upgrade to FFmpeg 8.1 for media transcoding](https://jellyfin.org/posts/jellyfin-release-12.0/#transcoding-and-media-handling), as well as [better handling of book and comic media](https://jellyfin.org/posts/jellyfin-release-12.0/#books-and-comics-properly-this-time). See the release notes for the [web client](https://github.com/jellyfin/jellyfin-web/releases/tag/v12.0) and [server](https://github.com/jellyfin/jellyfin/releases/tag/v12.0) for a full list of changes.
