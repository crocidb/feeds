[Version 0.46](https://github.com/zellij-org/zellij/releases/tag/v0.46.0) of the [Zellij](https://zellij.dev/) terminal workspace has been released.

>
>
> This release includes a major addition in Zellij: Zellij is now also a desktop terminal. To run it: zellij terminal. It works on linux, mac and windows.
>
>
>
> Nothing changes for the normal multiplexer - Zellij can still run inside another terminal. Both sessions are the same and can be shared.
>
>

Additional features in this release include a GUI settings screen, session previews, and right-click menu. See [this walkthrough](https://zellij.dev/news/terminal-inbox-session-previews/) for more on the 0.46 release.
