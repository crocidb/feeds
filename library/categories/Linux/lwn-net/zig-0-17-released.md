[Version 0.17](https://ziglang.org/download/0.17.0/release-notes.html) of the Zig programming language has been released.

>
>
> This release features **5 months of work**: changes from **206 different contributors**, spread among **925 commits**.
>
>
>
> Originally predicted to be shorter, this release cycle ended up [being] substantial, with the [Build System](https://ziglang.org/download/0.17.0/release-notes.html#Build-System) reworked, including the introduction of the [Build Server Protocol](https://ziglang.org/download/0.17.0/release-notes.html#Build-Server-Protocol), and the [ELF Linker](https://ziglang.org/download/0.17.0/release-notes.html#ELF) enhanced to the point where we expect [Incremental Compilation](https://ziglang.org/download/0.17.0/release-notes.html#Incremental-Compilation) to work for everyone on x86\_64-linux.
>
>
