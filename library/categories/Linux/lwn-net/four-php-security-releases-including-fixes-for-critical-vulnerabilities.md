The PHP Project has announced the release of PHP [8.5.13](https://www.php.net/ChangeLog-8.php#8.5.13), [8.4.28](https://www.php.net/ChangeLog-8.php#8.4.28), [8.3.37](https://www.php.net/ChangeLog-8.php#8.3.37), and [8.2.36](https://www.php.net/ChangeLog-8.php#8.2.36). Each contains a number of security and bug fixes, including several fixes for critical vulnerabilities that could allow remote-code execution. According to the project's [pre-release announcement](https://www.php.net/archive/2026.php#2026-11-18-1) on November 18, all of the vulnerabilities of critical severity "
> require either non-default configuration or uncommon setups

". See the release notes for details; Linux vendors and projects should be releasing updated packages soon.
