[Version 160](https://www.firefox.com/en-US/firefox/160.0/releasenotes/) of the Firefox web browser has been released. Notable features in this release include the ability to block sites from asking to handle "mailto:" links, ability to play Matroska files with FLAC, MP3, or PCM audio, playback speed controls in the [picture-in-picture](https://support.mozilla.org/kb/about-picture-picture-firefox) video player, and a new [Mini Window feature](https://connect.mozilla.org/t5/discussions/mini-window-beta-is-going-live-in-firefox-160-and-we-want-your/m-p/144137#M59048) that is in early development.
