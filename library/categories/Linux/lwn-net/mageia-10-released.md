[Mageia 10](https://www.mageia.org/en/10/) has been released with the 6.18 Linux kernel, DNF 5.4.0, RPM 4.20.1, and an increase in hardware requirements for x86 32-bit systems; users now need a CPU with SSE2 features. See the [release notes](https://wiki.mageia.org/en/Mageia_10_Release_Notes) for a full list of updates, and the [errata page](https://wiki.mageia.org/en/Mageia_10_Errata) for known problems.
