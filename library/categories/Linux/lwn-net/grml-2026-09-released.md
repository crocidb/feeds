[Version 2026.09](https://grml.org/changelogs/README-grml-2026.09/), [code-named](https://grml.org/faq/#releasename) "Hättiwaritätti", of the Debian-based Grml live Linux distribution for system administrators has been released. It is based on packages from the upcoming Debian 14 ("forky") release. Notable changes include an update to the Linux 7.1.8 kernel, support for booting from exfat-formatted USB devices, and an update to GNU Screen 5.0.1.
