[Version 161.0](https://www.firefox.com/en-US/firefox/161.0/releasenotes/) of the Firefox web browser has been released. Notable changes in this release include the [ability to assign a shortcut](https://support.mozilla.org/en-US/kb/customize-keyboard-shortcuts-firefox) to copy the current tab's URL, addition of a menu item for [Tab Groups](https://www.firefox.com/en-US/features/tab-groups/), and the [built-in VPN can be turned off or on for specific sites](https://connect.mozilla.org/t5/discussions/coming-in-firefox-161-choose-which-websites-always-use-the-built/td-p/147674#M60589). There are also a [number of security fixes](https://www.mozilla.org/en-US/security/advisories/mfsa2026-131/) in this release.
