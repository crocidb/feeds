The Debian project has wrestled with the topic of LLM usage for years, which culminated in a [general-resolution vote](https://lwn.net/Articles/1087134/) this August. The project [voted in favor](https://lwn.net/Articles/1091231/) of the fifth, out of eight, option: "[Responsible Use of Generative AI](https://www.debian.org/vote/2026/vote_002#texte)". With the door open to LLM use, the [DFSG, Licensing & New Packages Team](https://wiki.debian.org/Teams/DFSG) (usually shortened to "DFSG team"), which is [relatively new](https://lwn.net/Articles/1043364/), has started to employ LLMs in sending out reviews of packages entering Debian's [new queue](https://wiki.debian.org/NewQueue?pow_referer=https://kagi.com/). The practice has raised a number of objections and questions about where lines should be drawn in the use of LLM-generated output.
