The [openSUSE Project](https://opensuse.org/) has been working on the [Agama installer](https://agama-project.github.io/) for four years; it was the default installer for [openSUSE Leap 16.0](https://lwn.net/Articles/1019688/) when it was released in 2025, and has been adopted by other openSUSE flavors as well. Now the project is gearing up to go all-in on Agama for [Tumbleweed](https://get.opensuse.org/tumbleweed/), the rolling-release edition that is meant to be where updates and new features land first. Even so, the community has concerns about losing some of [YaST's](https://yast.opensuse.org/) legacy functionality and the impact on installing Tumbleweed on systems that have less RAM.
