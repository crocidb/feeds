[Version 16.0](https://blog.torproject.org/new-release-tor-browser-160/) of the [Tor Browser](https://download.torproject.org/tor-browser-for-desktop/) has been released. This is the first stable version based on Firefox ESR 153. Notable changes in this release include support for Linux on 64-bit Arm, redesigned settings, and a "generic window titles" feature to help prevent other applications from snooping on one's browser activity. [Tor Browser for Android](https://download.torproject.org/tor-browser-for-android/) has had a number of interface updates to Google's Material Design 3 design language.

This release also follows Firefox in ending support for 32-bit x86 Linux systems. See the [full changelog](https://gitlab.torproject.org/tpo/applications/tor-browser-build/-/raw/maint-16.0/projects/browser/Bundle-Data/Docs-TBB/ChangeLog.txt) for all of the updates and bug fixes.
