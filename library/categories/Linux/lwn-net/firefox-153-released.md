[Version 153.0](https://www.firefox.com/en-US/firefox/153.0/releasenotes/) of the Firefox web browser has been released. Notable changes in this release include a change to the default local-file-access permissions for extensions, enabling LAN restrictions by default for all users, a visual indicator when a web site has access to the user's location, the ability to merge PDFs and add images as pages within PDFs, as well as experimental support for the [JPEG XL](https://jpegxl.info/) image format.

See the [release notes for developers](https://developer.mozilla.org/en-US/docs/Mozilla/Firefox/Releases/153) for all changes that affect web developers, and [security advisories](https://www.mozilla.org/en-US/security/advisories/mfsa2026-68/) for vulnerabilities fixed in this release.
