[CachyOS](https://cachyos.org/), a performance-focused distribution based on [Arch Linux](https://archlinux.org/), has announced its [November 2026](https://cachyos.org/blog/2611-november-release/) release. Notable changes in this release include a new recovery environment ("cachyos-recovery") for rolling back broken systems, Easy Anti-Cheat (EAC) v2 support for games that require EAC to run, version 2.0.0 of the CachyOS Package Installer, and more.
