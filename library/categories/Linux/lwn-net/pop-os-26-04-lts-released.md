System76 has [announced](https://system76.com/blog/post/pop_os-26-04-lts-has-landed) the release of Pop!\_OS 26.04 LTS, which is based on Ubuntu 26.04 LTS. Notable features in this release include drawing tablet support, automatic updates, a number of new COSMIC applications, and more. Updates for users on Pop!\_OS 24.04 LTS will be enabled in December.

LWN [last covered](https://lwn.net/Articles/984638/) Pop!\_OS and an early version of its COSMIC desktop in August 2024.
