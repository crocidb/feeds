The Register [looks forward](https://www.theregister.com/software/2026/09/16/fedora-45-beta-drags-the-linux-console-into-the-21st-century/5296873) to the upcoming Fedora 45 release.

>  The biggest surprise is that Linux's legacy in-kernel console – the text-mode interface normally hidden beneath the GUI – has been replaced with a software-controlled alternative. The replacement is [kmscon](https://github.com/kmscon/kmscon#kmscon), a userspace terminal emulator that has been in development for more than a decade.
