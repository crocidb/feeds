Version 31.1 of the Emacs editor has been released. There is a long list of changes including the removal of the [Emacs dumper](https://lwn.net/Articles/707615/), a new user Lisp directory feature, a "Send to..." menu item in context-menu-mode, and many other changes; see [the NEWS file](https://www.gnu.org/software/emacs/news/NEWS.31.1) for more information. Mickey Petersen, author of *Mastering Emacs*, also has a [rundown](https://www.masteringemacs.org/article/whats-new-in-emacs-311) of some of the quality-of-life features appearing in this release.
