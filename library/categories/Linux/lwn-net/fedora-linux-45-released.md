[Fedora Linux 45](https://fedoramagazine.org/announcing-fedora-linux-45/) has been released. This includes all editions: [Fedora Workstation](https://fedoraproject.org/workstation/), [Fedora KDE Plasma Desktop](https://fedoraproject.org/kde/), [Fedora Server](https://fedoraproject.org/server/), [Fedora Cloud](https://fedoraproject.org/cloud/), [Fedora CoreOS](https://fedoraproject.org/coreos/), and [Fedora IoT](https://fedoraproject.org/iot/), as well as the [Atomic Desktops](https://fedoraproject.org/atomic-desktops/) and [Spins](https://fedoraproject.org/spins/).

This release adds support for [installation on Stratis storage](https://fedoraproject.org/wiki/Releases/45/ChangeSet#oo7_Secrets_Service_Provider) using Anaconda or Kickstart installs, [retires unmaintained VPN plugins](https://fedoramagazine.org/migrating-away-from-unmaintained-networkmanager-vpnpluginsvpnc-and-fortisslvpn/) for NetworkManager, and updates Fedora's desktop environments, developer toolchains, and system packages. See the [Fedora wiki ChangeSet page](https://fedoraproject.org/wiki/Releases/45/ChangeSet) for a list of major changes.
