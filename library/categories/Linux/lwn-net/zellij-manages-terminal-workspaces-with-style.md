[Zellij](https://zellij.dev) is a relatively new entrant in the [terminal-multiplexer](https://en.wikipedia.org/wiki/Terminal_multiplexer) category. Like [GNU Screen](https://www.gnu.org/software/screen/) and [tmux](https://github.com/tmux/tmux/wiki) it gives users the ability to manage a workspace inside a terminal with split panes, provides session management, and so forth; but Zellij also includes a web server for browser access to a terminal session, is extensible via a plugin API, and is likely more beginner-friendly than its predecessors. Its most recent release, [version 0.46](https://github.com/zellij-org/zellij/releases/tag/v0.46.0), adds a standalone terminal emulator, a built-in inbox for notifications, and a settings screen so users can configure the application without fussing with configuration files. While the low version number might suggest that it is not yet ready for serious use, it seems stable and full-featured enough to meet the needs of many users.
