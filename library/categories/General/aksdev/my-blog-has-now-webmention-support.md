Hey there, I have been reading about [IndieWeb](https://indieweb.org/) and found out about something called [Webmentions](https://indieweb.org/Webmention).

I am using [Webmention.io](https://indieweb.org/webmention.io) for mine for now, I may in future host my own Webmention system, though I am rather lazy so IDK.

I am still quite new at this, but I am interested in how it works.

Feel free to webmention this post! I think you can use something like [telegraph](https://telegraph.p3k.io/) for sending them.

Also if I set my [brid.gy](https://brid.gy/), any replies to the post that mentions this blogpost should show up below. If there's no mentions, nothing is shown. (You need JS enabled to see them).

Uh, that's all. Let's see how this goes. :)
