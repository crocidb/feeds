**Edit:** I disabled Anubis for now.

The thing is, my blog is really not that affected by the bots, and I have to admit, I prefer to have my blog as Javascript free as possible. (I still have goatcounter javascript but it can be blocked, Anubis can't.)

However, I have now tested out the Anubis stuff and can enable it pretty quickly if needed!

Nothing against Anubis, I think it's a great tool and it was quite easy to get set up. But for now, I don't think my blog really *needs* it.

Hey all, just wanted to let you know that I added the [Anubis](https://github.com/TecharoHQ/anubis/) "AI" scraping blocker tool thing to my blog now.
