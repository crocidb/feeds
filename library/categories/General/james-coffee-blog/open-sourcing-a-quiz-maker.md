***Update June 25th, 2026**: Kami has made a* [*web-based quiz maker that I recommend*](https://jamesg.blog/2026/06/25/make-your-own-web-quizzes)*. My script below still works, but the web-based maker is much more intuitive and is likely what I will use for future quizzes.*

When I designed my [“Which HTML element are you?” quiz](https://jamesg.blog/html-quiz), I wrote all of the HTML and JavaScript required to make the quiz work by hand. It took a lot of work, but it was a lot of fun! I used that code as the template for my second quiz, the [Blogger Archetype Quiz](https://jamesg.blog/blogger-archetypes). With that said, I had to change a lot of values by hand. Working on the second quiz reminded me of my ambition to make a tool that others could use to make similar quizzes.

Both the afore-linked quizzes provide several multiple choice questions. Each choice in each question maps to one or more of several potential results. For example, the “Watch the world go by.” answer to the “When you are spending time outdoors, what do you like to do best?” question in the Blogger Archetype Quiz maps to the “Explorer” archetype.

I have spent some time today creating a [single Python script](https://codeberg.org/capjamesg/html-quiz-maker/src/branch/main/app.py), open source under an MIT license, to generate quizzes like the ones above. The script provides several comments marked as `TODOs` which specify what you need to set: for example, a name for the quiz, the potential results, the questions and how each answer maps back to a result. I hope that this script will make it easier for me, and others, to make quizzes in the future.

My original idea was to create a web page with client-side JavaScript that would let you make a quiz but, after some tinkering, doing this well would require significant work to build. I would need some means of storing quiz information in the browser so that if a user accidentally refreshed the page their work would persist (because the forms would be generated by JavaScript, I can’t rely on the browser remembering inputs if the user refreshes the page).

With these limitations in mind, I ended up making a Python script which generates the requisite HTML and JavaScript. I chose Python because it is the language with which I am most familiar. The script outputs a HTML file with only the exact code you need to make the quiz work. There isn’t even a `html` tag in the output file: the code generated by the file can be copied into a web page. Importantly, the Python script is a single file so you don’t need to clone a whole repository to use it <sup id="f-1">1</sup>, and the script requires no dependencies so you don’t need to install anything other than Python to use it.

Ideally, this would all be a website that let you make a quiz, save the information for later, and copy-paste the HTML and JavaScript you need. I might build that one day, because having a Python script as the way to generate a quiz isn’t necessarily ideal. With that said, by open sourcing my code I hope that it will make it easier for people out there to make a quiz!

If you make your own quiz, do let me know. And if you feel inspired to make a better generator that gives someone HTML they can use on their own site (rather than being an embedded service), please bring the idea to life.

<sup class="footnote-definition-label" id="f-2">1</sup>

Keeping everything in one file has the consequence that the code is messy. I don’t love this because it makes it hard to know what the code is doing. Interpolating Python text into JavaScript is messy, too, and means the code is more verbose than it should need to be. Again, I really want something better to exist. I hope someone brings a better option to life!
