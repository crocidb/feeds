When I start writing, sometimes I go to the search engine on my website to see if I have written about a topic before. I did this when I was writing [background; foreground](https://jamesg.blog/2026/05/22/background-foreground). I had been thinking about the contrast between backgrounds and foregrounds for a while, so I wondered if I had any posts on the topic.

I typed “background and foreground” into my site search engine with hope that the tool would interpret the query as “show posts that include the words ‘background’ and ‘foreground’”. To my surprise and delight, the search engine did return results in that way. I last worked on the tool several months ago so I couldn’t quite remember what features were available. Using the “and” feature today, it was almost like past me did future me a favour, building something that might be handy in the future.

In background; foreground, I spoke about my blog moving from the background to the foreground and back in a cycle. The same is true of many of the tools I use and love, too: they are there when I need them, and move into the background when I don’t. My blog search is there when I need to find a blog post. My blog is there when I want to write and share my thoughts with friends and the world. Sometimes, on a day like today, a tool comes into the foreground not just because it is there, but because it does exactly the thing I need.

There is something really wonderful about making your own tools, and more generally making an intentional choice to use a tool that seems to fit with the way you work: the tool might still surprise you years on with what it can do.
