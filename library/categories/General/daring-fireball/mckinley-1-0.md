Crackerjack new Mac app for creating and editing custom [SF Symbols](https://developer.apple.com/sf-symbols/), from developer Amy Worrall:

>
>
> McKinley is an all-in-one studio for drawing and annotating SF Symbols. It bundles vector tools with knowledge of the SF Symbols structure, so you can edit one set of objects across multiple weights, sizes and colours. Import SVG or start from scratch, live preview your work using Apple’s own renderer, and export directly to Xcode, so you never need touch the SF Symbols app again!
>
>

McKinley is Mac-assed out the wazoo:

* Rich AppleScript support, including a library of practically useful example scripts.
* Quick Look previews and thumbnails for documents.
* A well-written comprehensive [user manual](https://mckinleysymbols.com/docs/welcome). (Me, [a few months ago](https://daringfireball.net/linked/2026/05/12/kagi-snaps): “There exist good products with bad or no documentation, but there are very few poor products with great documentation.”)

I mean just look at McKinley. It’s both beautiful and quite obviously [a serious professional tool](https://mastodon.social/@marioguzman/117230477915225971). McKinley is a $60 one-time purchase, and there’s a 15 percent launch discount this week only (taking the price to just $51). What a remarkable 1.0.
