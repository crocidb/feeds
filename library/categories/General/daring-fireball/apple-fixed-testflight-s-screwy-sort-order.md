[I wrote two weeks ago](https://daringfireball.net/2026/08/apple_testflight_list_sort_order) about how the v4.3.0 update to TestFlight (released on July 21) broke the sort order for apps in the sidebar. Apple yesterday released v4.3.1, with these helpful release notes:

>
>
> This update includes stability improvements and bug fixes.
>
>

One of the weirdest parts about this sort-order bug is that [it only affected some people](https://daringfireball.net/linked/2026/08/24/more-on-testflights-screwy-sort-order). I was obviously one of them; [so was John Siracusa](https://mastodon.social/@siracusa/117135117635246786). For both of us, yesterday’s v4.3.1 update fixes the bug.
