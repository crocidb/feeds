My thanks to WorkOS for sponsoring last week at DF. An agent can’t click through a signup page built for humans, so give it something it can read instead. Publish an auth.md file and agents register themselves without ever touching a browser login, and the user never gets pulled out of what they were doing.

With WorkOS auth.md, enroll in the dashboard and AuthKit publishes the file. Agents read it, register, and get scoped, short-lived credentials you control.
