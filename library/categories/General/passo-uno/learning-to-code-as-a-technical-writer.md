A recurring question from people entering the tech writing profession is “Should I learn to code?”. This query has become hugely popular in the docs-as-code age, where writers and developers live in the same DevOps trenches, eating the same CI/CD rations and publishing docs using [broken tools](https://passo.uno/docs-as-code-tools-open-standards/) that often lack maintainers.

My answer is “These are not the learnings you’re looking for.”
