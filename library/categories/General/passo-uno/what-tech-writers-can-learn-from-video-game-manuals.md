I’m not only a technical writer and an avid collector of [old manuals](https://passo.uno/why-collect-read-old-computer-manuals/): I’m also a gamer. One of the bits I always enjoyed about video games were the manuals, from the slim booklets that accompanied arcade games to the hefty guides that helped build virtual worlds in our heads while we waited for a few kilobytes to load in memory. Those manuals still hold valuable lessons for the software documentation we write today.
