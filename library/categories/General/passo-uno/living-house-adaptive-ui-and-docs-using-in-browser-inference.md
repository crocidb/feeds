One of my favorite video games of all time is [Control](https://www.remedygames.com/games/control). The main location of the game, the brutalist Oldest House, reacts to the player’s actions and rearranges itself dynamically, moving slabs of concrete around like a sentient being. Now, what if user interfaces and docs could react dynamically to the user and seek to adapt to their behavior like Control’s levels? Would it still be usable? Would the documentation drift too much? I explored these questions through an experimental application that uses in-browser LLMs.
