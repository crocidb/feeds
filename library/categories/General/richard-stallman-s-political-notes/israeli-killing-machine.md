 An Israeli machine learning system [recommended 1000 "targets" a day](https://www.theguardian.com/world/2026/jul/06/israel-command-system-identified-850000-targets-gaza-lebanon-war-supplier-elbit-systems) in Gaza and Lebanon, but they could only check some 50 per day to see if they were really HAMAS or Hezbollah combatants. Israel wanted to attack more than that, so skipped the checking step.
