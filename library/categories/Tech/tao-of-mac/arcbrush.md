[ArcBrush](https://arcbrush.com?utm_campaign=unsolicited_traffic&utm_medium=web&utm_source=taoofmac.com) is a native C++ node-based image editor for Windows, macOS and Linux, built around reusable, non-destructive processing graphs. Its 97 nodes cover image input, colour and palette operations, transforms, filters, compositing and export–effectively turning the sort of repeatable processing chain that usually ends up as an [ImageMagick](/space/cli/imagemagick) invocation into something visual and interactive.

The graph stays live as parameters and source files change, and the same pipeline can fan out across entire folders, colour variants and output sizes. There are dedicated tools for sprite-sheet slicing and assembly, filename templates, watched files and multi-format export, which makes it particularly interesting for game assets and other workflows where the same source material has to be rendered several different ways.

The free edition covers the complete 8-bit editor for personal and non-commercial use. [ArcBrush Pro](https://arcbrush.com/pricing?utm_campaign=unsolicited_traffic&utm_medium=web&utm_source=taoofmac.com) is a $49 perpetual licence that adds commercial use, 32-bit floating-point processing and high-bit-depth PNG, TIFF and OpenEXR output (including OCIO colour spaces), without activation or a machine-bound licence.

Most processing happens locally, although the optional cloud background-removal and upscaling nodes upload their inputs. [Usage telemetry](https://arcbrush.com/privacy?utm_campaign=unsolicited_traffic&utm_medium=web&utm_source=taoofmac.com) is enabled by default but can be disabled without affecting the editor–a distinction worth keeping in mind if local processing is part of the attraction.
