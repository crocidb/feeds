[Rewind](https://rewind.ai?utm_campaign=unsolicited_traffic&utm_medium=web&utm_source=taoofmac.com) is an iOS and Mac application that records what is in your screen (in iOS, it is implemented mostly as a browser extension that only records what you browse) and affords the ability to go back in time.

It predates [Windows 11](/space/com/microsoft/windows)’s “Recall” feature by around a year, and has inspired a number of other implementations.
