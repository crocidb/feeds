Tools
----------

](/space/markup/rss#tools)

* [Fusion](https://github.com/0x2E/fusion?utm_campaign=unsolicited_traffic&utm_medium=web&utm_source=taoofmac.com) — Lightweight self-hosted RSS reader (Filed 2026-11-07.)
* [Feedly Pro](https://feedly.com/i/pro?utm_campaign=unsolicited_traffic&utm_medium=web&utm_source=taoofmac.com) — Paid tier of the Feedly feed reader (Filed 2026-11-07.)
* [Miniflux](https://miniflux.app/?utm_campaign=unsolicited_traffic&utm_medium=web&utm_source=taoofmac.com), an opinionated feed reader with Fever API support (written in Go, uses Postgres as backend)- [Inkwell](https://codeberg.org/kendal/inkwell?utm_campaign=unsolicited_traffic&utm_medium=web&utm_source=taoofmac.com) - a simple RSS aggregator optimized for reading on e-ink devices

* [Page2RSS](http://page2rss.com/?utm_campaign=unsolicited_traffic&utm_medium=web&utm_source=taoofmac.com), a service to track web page changes.
* [RSSOwl](http://www.rssowl.org?utm_campaign=unsolicited_traffic&utm_medium=web&utm_source=taoofmac.com), a [Java](/space/dev/java)-based aggregator.
* [Raggle](http://www.raggle.org/?utm_campaign=unsolicited_traffic&utm_medium=web&utm_source=taoofmac.com), a [Ruby](/space/dev/ruby)-based CLI aggregator.
* [RSS Merge](http://brad.touesnard.com/aggregate/?utm_campaign=unsolicited_traffic&utm_medium=web&utm_source=taoofmac.com) (uses [LastRSS](http://lastrss.webdot.cz/?utm_campaign=unsolicited_traffic&utm_medium=web&utm_source=taoofmac.com))
* [Planet](http://planetplanet.org/?utm_campaign=unsolicited_traffic&utm_medium=web&utm_source=taoofmac.com), a flexible aggregator that powers a number of sites.
* [Hep](http://www.fettig.net/projects/hep/?utm_campaign=unsolicited_traffic&utm_medium=web&utm_source=taoofmac.com) - a very nice [Python](/space/dev/python) aggregator with a [POP3](protocol/pop3)/[IMAP](protocol/imap) interface.
* [FeedBurner](http://www.feedburner.com/fb/a/home?utm_campaign=unsolicited_traffic&utm_medium=web&utm_source=taoofmac.com) - slices and dices feeds (also converts between [RSS](/space/markup/rss) and [Atom](markup/atom)). I expect it to start adding advertisements somewhere along the line.
* [rss2mail](http://exo.org.uk/code/rss2mail/?utm_campaign=unsolicited_traffic&utm_medium=web&utm_source=taoofmac.com) - [Perl](/space/dev/perl) implementation
* [Mimir](http://mimir.ik.nu/?utm_campaign=unsolicited_traffic&utm_medium=web&utm_source=taoofmac.com), [RSS](/space/markup/rss) feeds via IM using [Jabber](/space/protocols/xmpp)
* [Tapestry - Comics via RSS](http://dwlt.net/tapestry/?utm_campaign=unsolicited_traffic&utm_medium=web&utm_source=taoofmac.com)
* [RSS Autodiscovery](http://www.keithdevens.com/weblog/archive/2002/Jun/03/RSSAuto-DiscoveryPHP?utm_campaign=unsolicited_traffic&utm_medium=web&utm_source=taoofmac.com) using [PHP](/space/dev/php)
* [nntp://rss](http://www.methodize.org/nntprss?utm_campaign=unsolicited_traffic&utm_medium=web&utm_source=taoofmac.com) (read [RSS](/space/markup/rss) feeds with a [News](/space/protocols/nntp) client. Neat.)
* [RSS Display](http://www.decafbad.com/twiki/bin/view/Main/RssDisplay?utm_campaign=unsolicited_traffic&utm_medium=web&utm_source=taoofmac.com) (a [Perl](/space/dev/perl) CGI)
* [Ultra-Liberal RSS Parser](http://diveintomark.org/projects/rss_parser/?utm_campaign=unsolicited_traffic&utm_medium=web&utm_source=taoofmac.com)
* [XSLT](XSLT) [blogroll](http://www.webweavertech.com/ovidiu/weblog/archives/000014.html?utm_campaign=unsolicited_traffic&utm_medium=web&utm_source=taoofmac.com) for [MovableType](MovableType)
* [Onyx RSS Parser](http://www.readinged.com/onyx/rss/?utm_campaign=unsolicited_traffic&utm_medium=web&utm_source=taoofmac.com) - a [PHP](/space/dev/php) parser
* [RSS to IM Gateway](http://freshmeat.net/projects/rss-im/?utm_campaign=unsolicited_traffic&utm_medium=web&utm_source=taoofmac.com)
* A [Python](/space/dev/python) [Bayesian](Bayesian) Classifier called [Reverend](http://www.divmod.org/Reverend/?utm_campaign=unsolicited_traffic&utm_medium=web&utm_source=taoofmac.com) that might well be useful for rating [RSS](/space/markup/rss) feeds
* [Magpie](http://magpierss.sourceforge.net/?utm_campaign=unsolicited_traffic&utm_medium=web&utm_source=taoofmac.com), a [PHP](/space/dev/php) [RSS](/space/markup/rss) parser
* [rss2pop3](http://sudaca.bloggedup.com/archives/000016.html?utm_campaign=unsolicited_traffic&utm_medium=web&utm_source=taoofmac.com)
* [Aggreg8](apps/Aggreg8)
* [Atom](markup/atom) and [RSS Feed Library](http://www.bitfolge.de/rsscreator-en.html?utm_campaign=unsolicited_traffic&utm_medium=web&utm_source=taoofmac.com) for [PHP](/space/dev/php)
* [Mailfeed](http://wonko.com/software/mailfeed/?utm_campaign=unsolicited_traffic&utm_medium=web&utm_source=taoofmac.com) - a [PHP](/space/dev/php) script that generates an [RSS](/space/markup/rss) feed off a [POP3](protocol/pop3) or [IMAP](protocol/imap) mailbox.
