### Use `vnc4server`, not `tightvncserver` ###

](/space/hw/raspberry_pi#use-vnc4server-not-tightvncserver)

If you’re using an older version of Raspbian and want to access your board via [VNC](/space/protocols/vnc), you should grab a copy of the `vnc4server` sources from [Ubuntu](/space/os/linux/distributions/ubuntu) and rebuild it on the Pi. `vnc4server` has much less latency and performs much better overall, at least for my use cases:

```
# on a Ubuntu box
$ mkdir tmp; cd tmp
$ apt-get source vnc4server
# find the source tree and rsync it across to the Pi
# ...time passes...

# on the Pi, cd into the source tree and do:
$ debuild -us -uc
# ...a lot of time passes...
$ cd ..; sudo apt-get install xbase-clients x11-apps; sudo dpkg -i vnc4server*.deb

```
