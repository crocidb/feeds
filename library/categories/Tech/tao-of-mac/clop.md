[Clop](https://lowtechguys.com/clop?utm_campaign=unsolicited_traffic&utm_medium=web&utm_source=taoofmac.com) is a macOS utility for optimising images, videos and PDFs, including images copied to the clipboard. It supports downscaling, format conversion and macOS Shortcuts, using tools such as pngquant, jpegoptim, ffmpeg and Ghostscript.

It is broader in scope than [ImageOptim](/space/apps/imageoptim), which focuses on image compression. Clop’s [source code](https://github.com/FuzzyIdeas/Clop?utm_campaign=unsolicited_traffic&utm_medium=web&utm_source=taoofmac.com) is available under GPLv3; the distributed app has free features and paid Pro features, with a trial.
