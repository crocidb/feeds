[Mole](https://github.com/tw93/Mole?utm_campaign=unsolicited_traffic&utm_medium=web&utm_source=taoofmac.com) is an open-source macOS maintenance toolkit with a terminal interface. Its `mo` command provides cleanup, app removal, disk-space analysis, system maintenance and live resource monitoring, including commands for removing build artifacts and old installers.

It requires macOS 12 or newer and supports both Intel and Apple Silicon Macs. It can be installed with `brew install mole`. The CLI is licensed under GPLv3; the [project website](https://mole.fit?utm_campaign=unsolicited_traffic&utm_medium=web&utm_source=taoofmac.com) also offers a separate native Mac app, which is not installed by the Homebrew CLI package.

Cleanup and removal commands can permanently delete files. Use their `--dry-run` previews and review the targets before proceeding; whitelists are available for cleanup and optimisation exclusions.

[AppCleaner](/space/apps/appcleaner) and [Disk Inventory X](/space/apps/disk_inventory_x#disk-inventory-x) cover some of the same app-removal and disk-analysis tasks with graphical interfaces.
