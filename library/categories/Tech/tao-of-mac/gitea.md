[Gitea](https://gitea.io/?utm_campaign=unsolicited_traffic&utm_medium=web&utm_source=taoofmac.com) is a very efficient, [Go](/space/dev/golang)-based [`git`](/space/cli/git) service that I have adopted as part of my [homelab](/space/blog/2022/02/12/1930) setup.

[

Additions
----------

](/space/apps/gitea#additions)

* [gitea-mirror](https://github.com/RayLabsHQ/gitea-mirror?utm_campaign=unsolicited_traffic&utm_medium=web&utm_source=taoofmac.com) — Web UI and scheduler for mirroring GitHub repositories and metadata to Gitea or Forgejo; other source and destination providers are beta (Filed 2026-11-07.)

* [opengist](https://github.com/thomiceli/opengist?utm_campaign=unsolicited_traffic&utm_medium=web&utm_source=taoofmac.com) is a small git-backed service that you can use to have a self-hosted Gist-like service.

* [caddy-gitea](https://github.com/42wim/caddy-gitea?utm_campaign=unsolicited_traffic&utm_medium=web&utm_source=taoofmac.com) is a Caddy module that can publish Gitea repositories in a `gh-pages`-like fashion.
