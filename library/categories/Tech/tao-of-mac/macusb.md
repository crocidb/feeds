[macUSB](https://macusb.app?utm_campaign=unsolicited_traffic&utm_medium=web&utm_source=taoofmac.com) is an open-source bootable USB creator for macOS, supporting macOS installers and Windows and Linux ISO images. It can download macOS installers from Apple or use local installer files, and includes SHA-256 checks and optional Windows setup automation.

It requires macOS Sonoma 14.6 or newer and runs on both Apple Silicon and Intel Macs. Creating installation media erases the selected USB drive; the project’s instructions also call for Full Disk Access and permission to run in the background.

It does a similar job to [Etcher](/space/apps/etcher), with extra handling for macOS installers. The [source code](https://github.com/Kruszoneq/macUSB?utm_campaign=unsolicited_traffic&utm_medium=web&utm_source=taoofmac.com) is available under the MIT license.
