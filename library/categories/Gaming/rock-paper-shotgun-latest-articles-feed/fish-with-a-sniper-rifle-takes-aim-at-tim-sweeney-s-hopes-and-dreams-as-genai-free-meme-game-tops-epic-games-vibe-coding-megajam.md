Epic Games are, as you're probably aware, going [big](https://www.rockpapershotgun.com/we-vibe-coded-a-new-epic-games-launcher-because-programming-is-hard-announce-company-were-somehow-supposed-to-see-as-a-serious-steam-competitor) [on](https://www.rockpapershotgun.com/no-more-hand-written-code-epic-reportedly-impose-ai-first-model-on-creators-of-new-disney-shooter-with-marvel-and-star-wars-characters) [genAI](https://www.rockpapershotgun.com/we-are-more-concerned-about-the-risks-of-moving-too-slowly-epic-get-more-specific-about-genai-use-in-unreal-engine-and-fortnite-development) at the moment. To the extent that, last month, the Tim Sweeney-helmed company announced the [Epic AI MegaJam](https://www.unrealengine.com/news/2026-epic-ai-megajam). Build a playable game in Unreal Engine or Unreal Editor for Fortnite with help from as many AI agents or tools as you like was the pitch.

So, naturally, sorting [the submissions](https://itch.io/jam/2026-epic-ai-megajam/entries) by 'Popular' turns up a game about a fish with a sniper rifle whose creator says they deliberately made it without using any generative AI.
