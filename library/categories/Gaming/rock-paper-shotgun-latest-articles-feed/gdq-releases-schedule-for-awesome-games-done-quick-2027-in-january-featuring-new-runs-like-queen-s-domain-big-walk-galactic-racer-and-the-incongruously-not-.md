Following the full [game list](https://gamesdonequick.com/games) for [Awesome Games Done Quick](https://www.rockpapershotgun.com/games/awesome-games-done-quick) being released a little while ago, GDQ have now published the full[ schedule](https://gamesdonequick.com/schedule/74) for the event running for a week from January 3rd through January 10th in Atlanta (and streamed on [Twitch](https://www.twitch.tv/directory/category/games-done-quick), of course). Included amongst the new games this year are 2026 releases like [Queen's Domain](https://www.rockpapershotgun.com/games/queens-domain), [Star Wars: Galactic Racer](https://www.rockpapershotgun.com/games/star-wars-galactic-racer), the Ocarina of Time remake, and [Castlevania: Belmont's Curse](https://www.rockpapershotgun.com/castlevania-belmonts-curse-complete-walkthrough), which all make a lot of sense as games practically made for speedrunning. Belmont's Curse, specifically, is set to be the event's final bonus game, only to be played if donation incentives are met (which I'm sure they will be, it's a Castlevania game at GDQ).
